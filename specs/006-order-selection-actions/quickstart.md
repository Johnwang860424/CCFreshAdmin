# Quickstart 驗證：訂單勾選出貨與匯出 CSV（跨頁選取）

手動驗證流程（無測試框架）。以 `npm run lint` 與 `npm run build` 把關型別，再依下列情境於瀏覽器驗收。

## 前置

```bash
npm run lint
npm run build   # 型別檢查（strict）
npm run dev     # 本機開發伺服器
```

- 以 `ALLOWED_EMAILS` 內帳號登入，進入「訂單管理」頁。
- 準備：某條路線下有 **超過一頁**（例如 >10 筆）自取訂單，且分屬 ≥2 個縣市；另有若干宅配訂單。

## 情境 1 — 勾選任意訂單並出貨（US1 / FR-001,003,006,007,009）

1. 於路線下拉選一條路線 → 表格出現該路線訂單，最前面每列有勾選框、表頭有全選框。
2. 未勾選任何訂單時：「出貨選取」「匯出選取訂單」為停用。
3. 勾選其中 2 筆 → 已選數量顯示「2」，兩顆按鈕啟用。
4. 按「出貨選取」→ 出現確認視窗，載明將清除 2 筆、警示無法復原並建議先匯出 → 按確定。
5. **預期**：僅那 2 筆消失、其餘保留；已選數量歸 0；路線清單與訂單清單刷新。

## 情境 2 — 勾選任意訂單並匯出 CSV（US2 / FR-004,005）

1. 勾選分屬不同縣市的 3 筆訂單，按「匯出選取訂單」。
2. **預期**：下載 `訂單_YYYY-MM-DD.xlsx`；開啟後只含那 3 筆，欄位＝取貨號/客戶姓名/取貨地點/購買清單/訂單總額/電話/備註；不同縣市各自成一個工作表分頁。
3. 資料未被清除；不改勾選再按一次可再次成功下載相同內容（可重複）。

## 情境 3 — 跨頁維持勾選（US3 / FR-002,008）

1. 將分頁設每頁 10 筆，確保有第 2 頁。
2. 第 1 頁勾 2 筆 → 翻到第 2 頁勾 1 筆 → 已選數量顯示「3」。
3. 翻回第 1 頁 → 先前 2 筆仍為勾選。
4. 按「匯出選取訂單」或「出貨選取」→ **預期**動作涵蓋全部 3 筆（非僅目前頁）。

## 情境 4 — 切換路線清空勾選（FR-011）

1. 於某路線勾選數筆（已選數量 >0）。
2. 將路線下拉切到另一條路線。
3. **預期**：勾選被清空、已選數量歸 0；新路線的訂單皆未勾選。

## 情境 5 — 邊界

- **篩選不清勾選**：勾選數筆後，在「於結果內篩選」輸入關鍵字縮小可見清單 → 已選數量不變；被篩掉但已勾選者仍計入後續動作。
- **部分已消失（FR-010）**：勾選數筆後，於他分頁/他視窗刪除其中一筆，再對原勾選執行出貨 → 動作成功，提示實際刪除筆數（少於送出數），不整批失敗。
- **0 筆**：全部取消勾選 → 兩顆按鈕停用，無法送出。

## 回歸（FR-012）

- 既有「出貨 / 匯出 CSV」（依路線／宅配整組）入口仍在且行為不變：整組匯出檔案格式與選取匯出一致（同一 `buildOrdersWorkbook`）。
